# TBOI Tears Test

A free, ad-free fan website for **The Binding of Isaac: Repentance+**. Select items and see how
your attack changes when they are combined: which item replaces your weapon, which adds an
effect, which changes the number of shots, and which specific interactions kick in. A live
animated preview shows how Isaac would shoot.

Useful mid-run: pick the items you have, then check whether the next item would transform your
tears or add an effect you don't want.

All synergy data comes from [The Binding of Isaac: Rebirth Wiki](https://bindingofisaacrebirth.wiki.gg),
with a link to the source for every rule. Nothing is invented.

**Status:** early development. See [ROADMAP.md](ROADMAP.md).
